# Object Detection Using TensorFlow: Weapon Detection in Security Cameras 🔍

## Overview
This project is a deep learning-based solution for detecting weapons in real-time using security camera footage. Leveraging TensorFlow and Keras, the model aims to enhance public safety by quickly identifying potential threats in monitored environments.

## Features
- Real-time object detection for weapons.
- Uses TensorFlow and Keras for model development.
- Scalable for deployment in large surveillance systems.
- Customizable for detecting additional objects.

## Technologies Used
- **TensorFlow**: For building and training the detection model.
- **Keras**: For streamlined deep learning workflows.
- **Python**: As the primary programming language.

## Prerequisites
Before you begin, ensure you have the following installed:
- Python 3.8 or newer
- TensorFlow 2.x
- Keras
- OpenCV
- NumPy
- Matplotlib
